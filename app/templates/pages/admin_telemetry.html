Inline completion acceptance rate per day

People active per day

Orange bars are Saturdays and Sundays.

Lines suggested and lines applied per day

Lines suggested is how many lines Copilot offered. Lines applied is how many lines were written into files. Agent mode writes lines straight into files without offering them first, so they count as applied but never as suggested. This is why lines applied can be higher than lines suggested.

Languages

These charts show the 15 languages with the most accepted suggestions. GitHub reports some languages under more than one name, for example ts, tsx and typescript, or cs and csharp. Each group is counted as one language, using the same names as the My Usage page. Values that are not languages, such as unknown and prompt, are not shown.
